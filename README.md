# Minesweeper-CPP 扫雷

用 C++ 写的经典扫雷游戏（控制台版），我的第一个完整 C++ 项目。

## 功能

- 9×9 棋盘，10 颗雷
- 双数组实现：`mine` 保存雷区，`show` 保存玩家可见区域
- 边界填充（11×11），统一处理四周格子的雷数统计，避免越界判断
- 坐标输入排雷，自动计算周围雷数
- 完整的胜负判定与菜单循环

## 如何运行

环境要求：Visual Studio 2022（勾选"使用 C++ 的桌面开发"工作负载）

1. 克隆仓库
   ```bash
   git clone https://github.com/majordanbarry/minesweeper-cpp.git
   ```
2. 双击打开 `game.slnx`
3. 按 `F5` 运行

## 玩法

运行后输入 `1` 开始游戏，然后依次输入行号和列号（1~9）翻开格子。
若翻开位置是雷则游戏结束；翻开全部 9×9 - 10 = 71 个安全格即为胜利。

## 技术实现

- **双数组设计**：`mine` 数组存雷（`'1'` 有雷 / `'0'` 无雷），`show` 数组存展示状态（`'*'` 未翻开 / 数字表示周围雷数），两个数组职责分离
- **边界填充技巧**：实际开 11×11，只显示中间 9×9，这样统计周围 8 格时不用额外判断数组越界
- **模块化**：声明与定义分离（`game.h` + `game.cpp`），入口单独放在 `main.cpp`
